# ⏱️ Contagem Regressiva (Countdown)

Um aplicativo web elegante e dinâmico que exibe uma contagem regressiva em tempo real para uma data ou evento específico. O painel atualiza automaticamente os dias, horas, minutos e segundos restantes na tela do usuário.

## 🔖 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo principal de praticar a manipulação de tempo e datas no JavaScript. A construção deste cronômetro exigiu o uso do objeto nativo `Date`, a aplicação de cálculos matemáticos para conversão de milissegundos e o domínio de funções assíncronas como o `setInterval` para garantir que os números se atualizem a cada segundo de forma fluida e sem falhas.

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias:

* ![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white) - Estrutura semântica para os blocos de tempo.
* ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white) - Estilização moderna, layout em grid/flexbox e responsividade.
* ![JavaScript](https://img.shields.io/badge/JavaScript-323330?style=for-the-badge&logo=javascript&logoColor=F7DF1E) - Lógica de cálculo de tempo, formatação de números e atualização do DOM em tempo real.

## ⚙️ Funcionalidades

- [x] Cálculo exato do tempo restante (Dias, Horas, Minutos e Segundos) até uma data-alvo.
- [x] Atualização automática e em tempo real da interface do usuário (a cada 1 segundo).
- [x] Formatação de números (adicionando um "0" à esquerda para números menores que 10, ex: `09` em vez de `9`).
- [x] Prevenção de tempo negativo (o cronômetro para no zero ou exibe uma mensagem de conclusão quando o tempo acaba).
- [x] Interface totalmente responsiva e adaptada para celulares e computadores.
